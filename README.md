# Arbeitsteilung-Schweiz

R-Markdown Code und Daten für ein Semesterprojekt zur Visualisierung der Arbeitsteilung in Schweizer Familien

Im Ordner `code/` befinden sich zwei Files mit dem R-Markdown code sowie zwei bereits geknittete HTML files.
Das File `processing_full_output.Rmd` wird zu einem File ohne Code Chunks geknittet (`processing_full_output.html`). Das File `processing.Rmd` produziert ein HTML File mit demselben Output aber mit den Code chunks (`processing.html`).
Um nur den geknitteten Output zu sehen, können die HTML files heruntergeladen werden und mit dem Browser of choice geöffnet werden. 

Die verwendeten Daten befinden sich im Ordner `data/raw/` und Stammen vom Schweizer Bundesamt für Statistik. [Datensatz 1](https://www.bfs.admin.ch/asset/de/22784588)  [Datensatz 2](https://www.bfs.admin.ch/asset/de/325794)
